## 0. 고르는 기준

이미 정한 게임 방향에 맞는지를 기준으로 비교했다.

| 기준 | 게임에서 이미 정한 것 |
| --- | --- |
| 낮은 피로도 | 관리 실패로 약해지지 않는다. 접속할 때마다 밀린 일이 없다 |
| 들여다보는 즐거움 | 다마고치처럼 캐릭터가 잘 크는지 본다. 모습과 행동이 바뀐다 |
| 미술 방향 제안 | 따뜻한 거점과 신비로운 원정지 |
| 구조 | 원정 단계를 자동으로 오르고, 20단계마다 관문 던전을 토벌한다 |
| 직업 | 전사 · 사냥꾼 · 마법사(공격·치유·축복 마법) |
| 재료 | 강화석 · 빛나는 조각 · 관문의 증표(가칭) |

## 후보 A. 등불과 안개 (추천)

> 세상은 오래전부터 짙은 안개에 덮여 있다. 모험가들은 등불을 들고 안개 속으로 들어가 길을 밝힌다. 밝혀진 길에는 이정표가 서고, 사람들은 그 길을 따라 조금씩 세상을 되찾는다.

| 게임 요소 | 이 세계관에서 |
| --- | --- |
| 거점 | 안개 가장자리의 **등불 여관**. 모험가가 쉬고, 전리품을 정리하고, 다음 원정을 준비한다 |
| 원정 | 등불을 들고 안개 속으로 나가 길을 밝히고 돌아온다 |
| 단계 | 밝힌 이정표의 수. "20번째 이정표까지 밝혔어요" |
| 구간 | 안개 너머의 지역 하나. 숲 → 늪 → 폐허 → … |
| 관문 | 지역마다 안개를 뿜는 **안개 둥지**. 우두머리를 토벌하면 그 지역 안개가 걷히고 다음 지역이 보인다 |
| 적 | 안개에서 태어난 짐승과 그림자. 지역마다 모습이 다르다 |
| 직업 | 전사는 앞에서 등불을 지키고, 사냥꾼은 안개 너머를 쏘고, 마법사는 빛을 다룬다 |
| 재료 | 등불 기름(강화석) · 별빛 조각(빛나는 조각) · 걷힌 안개의 인장(관문의 증표) |
| 성장 보고 | "안개 속에서 은빛 장궁을 찾았어요. 22번째 이정표까지 밝혔어요" |

- **어울리는 점:** 따뜻한 거점(불 켜진 여관)과 신비로운 원정지(안개)가 세계관 자체에 들어 있다. 토벌하면 지역 지도가 밝아지는 장면으로 진행을 눈에 보이게 할 수 있다. 위협이 무섭기보다 신비롭다.
- **주의할 점:** 안개·등불은 흔한 소재라 지역과 우두머리에서 개성을 내야 한다.
- **화풍 제안:** 따뜻한 주황 불빛의 거점과, 푸르고 흐린 원정지의 대비.

## 후보 B. 하늘 군도

> 대지는 구름 바다 아래로 가라앉았다. 사람들은 떠다니는 섬에 모여 산다. 모험가들은 작은 비행선을 타고 구름 아래 섬들을 탐사하고, 물자와 보물을 가져온다.

| 게임 요소 | 이 세계관에서 |
| --- | --- |
| 거점 | 작은 섬 위의 **비행선 정박장** |
| 원정 | 비행선을 타고 구름 아래 섬을 다녀온다 |
| 단계 | 탐사한 섬의 깊이(고도) |
| 관문 | 구간마다 가로막는 **폭풍의 벽**. 그 안의 우두머리를 토벌하면 폭풍이 걷힌다 |
| 재료 | 정제한 하늘돌 · 구름 수정 · 폭풍의 핵 |

- **어울리는 점:** 비행선이 출발하고 돌아오는 장면이 원정 반복과 잘 맞는다. 거점(섬)을 꾸미는 재미를 키우기 좋다.
- **주의할 점:** 비행선·섬 배경 그림이 많이 필요하다. 전사·사냥꾼·마법사와의 연결이 약간 느슨하다.

## 후보 C. 작은 모험가

> 모험가는 손바닥만 한 작은 사람들이다. 버섯 마을에 살며, 사람들이 떠난 오래된 정원과 집을 탐험한다. 그들에게 화단은 숲이고, 연못은 바다이고, 낡은 다락방은 던전이다.

| 게임 요소 | 이 세계관에서 |
| --- | --- |
| 거점 | 큰 버섯 아래의 **버섯 마을** |
| 원정 | 정원 · 연못 · 창고 · 다락방으로 나갔다 돌아온다 |
| 관문 | 구간마다 사는 큰 생물의 둥지(사마귀, 쥐, 까마귀 같은 우두머리) |
| 장비 | 바늘 검, 잔가지 활, 민들레 지팡이처럼 주운 물건으로 만든 장비 |
| 재료 | 반짝이는 단추 · 유리구슬 조각 · 큰 생물의 깃털 |

- **어울리는 점:** 다마고치처럼 '작은 존재를 돌보는' 감성과 가장 잘 맞는다. 장비 모습이 재미있고(병뚜껑 방패 등), 외형 변화로 애착을 만들기 좋다.
- **주의할 점:** 귀여운 쪽으로 기울어서 전투의 긴장감이 약하다. 곤충이 우두머리라 싫어하는 사람이 있을 수 있다.

## 후보 D. 이전 기획의 다크 판타지를 순하게

> 신을 믿던 나라가 무너졌다. 사람들이 신의 기적이라 믿었던 것은 사실 세상을 갉아먹는 병이었다. 살아남은 모험가들은 버려진 수도원에 모여, 무너진 땅을 조금씩 되찾는다.

- 링크해 준 세션(2026-10-26~27)의 세계관이다. 그 기획에 있던 잠식, 습격, 결정 지점 같은 관리 요소는 빼고 이야기와 분위기만 가져온다.
- **어울리는 점:** 이미 이야기 흐름(마을 주변 → 경계 지역 → 깊은 지역 → 진실)이 정해져 있어서, 구간마다 이야기가 조금씩 드러나는 구조를 바로 쓸 수 있다.
- **주의할 점:** 무겁고 어두운 분위기가 '따뜻한 거점, 낮은 피로도, 다마고치 감성'과 부딪친다. 수도원을 따뜻한 쉼터로 그리더라도 원정지는 계속 음울하다.

## 비교

| 기준 | A. 등불과 안개 | B. 하늘 군도 | C. 작은 모험가 | D. 순한 다크 판타지 |
| --- | :---: | :---: | :---: | :---: |
| 따뜻한 거점 | ◎ | ○ | ◎ | △ |
| 신비로운 원정지 | ◎ | ◎ | ○ | ○ |
| 들여다보는 애착 | ○ | ○ | ◎ | △ |
| 관문 = 길이 열림의 표현 | ◎ (안개가 걷힘) | ○ (폭풍이 걷힘) | ○ | ○ |
| 세 직업과의 연결 | ◎ | ○ | ○ | ◎ |
| 이야기를 이어가기 | ○ | ○ | △ | ◎ |
| 필요한 그림 양 | 보통 | 많음 | 보통 | 보통 |

**추천: A. 등불과 안개.** 정해 둔 게임 구조(원정으로 길을 밝히고, 관문을 깨면 다음 지역이 열림)를 세계관이 그대로 설명해 준다. 따뜻함과 신비로움을 둘 다 갖춘다. C는 애착이 가장 강하지만 전투 분위기가 약하고, D는 이야기는 깊지만 낮은 피로도 감성과 맞지 않는다.

섞는 것도 가능하다. 예: A의 구조에 C처럼 작은 거점 꾸미기 감성을 더하기, A의 안개 속에서 D처럼 무너진 옛 왕국의 흔적이 조금씩 드러나기.

## 고른 다음에 정할 것

1. 게임 제목
2. 첫 구간(1~20단계) 지역과 첫 관문의 이름·우두머리
3. 거점의 모습과 거점에 있는 인물(안내 역할 하나)
4. 직업별 첫인상 대사와 모험가의 성격 몇 가지
5. 재료·기술·장비 가칭을 세계관 이름으로 바꾸기
