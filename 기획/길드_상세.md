# 길드와 길드 섬

- 연결 문서: [RP_교류.md](./RP_교류.md), [파티_상세.md](./파티_상세.md), [캐릭터_도트그리기.md](./캐릭터_도트그리기.md)
- 상태: 사용자 방향은 확정이고, 세부 규칙과 수치는 제안이다.

## 0. 확정 사항

| 구분 | 내용 |
| --- | --- |
| 사용자 확정 (2026-11-01) | 길드를 만들면 **길드 섬**도 생긴다 |
| 사용자 확정 (2026-11-01) | 큰 토벌은 길드나 섬 모임끼리, 정해진 시각에 모여 있는 사람이 간다 |
| 원칙 (제안) | 길드는 **모이는 곳**이다. 길드에 들었다고 능력치가 오르지 않는다. 길드 레벨, 기부 의무, 출석 의무를 두지 않는다 |

## 1. 만들기와 가입 (제안)

| 항목 | 내용 |
| --- | --- |
| 만드는 조건 | 첫 관문을 깬 모험가. 골드 10,000 |
| 이름 | 2~8자. 길드 이름이 곧 길드 섬 이름이다 |
| 깃발 | 도트 편집기로 16 × 16 깃발을 그린다. 길드 섬 깃발과 길드원 프로필에 보인다 |
| 인원 | **최대 32명** (사용자 확정 2026-11-01. 큰 토벌 8명 × 4무리와 맞춘다) |
| 가입 | 길드가 "누구나 가입 / 신청 후 승인 / 초대만" 중 하나를 고른다 |
| 한 사람 | 길드 하나에만 든다. 나가는 것은 언제든 바로 된다. 새 길드에는 하루 뒤에 들 수 있다 |
| 역할 | 길드장 1, 관리자 최대 3, 길드원. 관리자는 공지·가입 승인·내보내기를 한다. 길드장이 7일 접속하지 않으면 가장 오래된 관리자에게 넘어간다 |

## 2. 길드 섬 (제안)

- 길드를 만들면 하늘 군도에 **길드 섬**이 하나 떠오른다. 길드원은 언제든 전송 마법으로 건너갈 수 있다. 초대가 필요 없다.
- **보이는 것:** 섬에 와 있는 길드원의 도트 캐릭터, 길드 깃발, 길드 이름표(파란색).
- **꾸미기:** 길드원이 가진 섬 장식(토벌 기념품 등)을 길드 섬에 **빌려 놓을** 수 있다. 놓은 사람이 언제든 거둬 간다. 기부가 아니므로 손해가 없다.
- **머물기:** 개인 섬과 같다. "머물기"로 두면 접속을 끊어도 섬에 남은 것으로 친다.
- **화면에 서는 인원:** 한꺼번에 최대 12명까지 그린다. 그보다 많으면 최근 말한 사람 순으로 보이고, 나머지는 "+N"으로 표시한다(휴대폰 화면 크기 때문).

## 3. 길드 섬 모임 (제안)

개인 섬의 "섬 모임 = 파티"([RP_교류.md](./RP_교류.md) 1-7)를 그대로 쓴다.

| 활동 | 길드 섬에서 |
| --- | --- |
| 함께 탐사 | 섬에 있는 길드원 중 최대 4명 |
| 관문 도전 | 섬에 있는 길드원 중 4명 고르기 |
| 큰 토벌 | 출발 시각(길드장이 정함, 기본 22:00)에 섬에 모여 있는 길드원. 화면에 **8칸 × 4무리 자리**가 뜬다. 빈칸을 누르면 그 무리에 들어가고, 고르지 않은 사람은 **자동으로** 앞 무리부터 채워진다(사용자 확정 2026-11-01). 무리마다 기록을 내고, 무리 안에서는 모두 같은 보상을 받는다 |

- 길드 큰 토벌 기록은 **무리 기록의 합**으로 남는다. 다른 길드와의 순위는 두지 않는다.
- 큰 토벌은 사람 기준 하루 한 번이므로, 길드 섬과 개인 섬 중 먼저 출발한 쪽으로 간다.

## 4. 대화 (제안)

- 대화 채널에 **길드**를 더한다(쉼터, 파티, 1:1, 길드).
- 모든 대화 줄에는 **프로필 그림**이 보인다. 올린 그림이 없으면 도트 캐릭터로 대신한다(사용자 확정 2026-11-01).
- 길드 대화에도 말풍선 대사(1-1)가 섞여 남는다. 끄는 설정은 같다.
- 공지 한 줄을 길드 섬 위에 띄운다. 관리자 이상이 고친다.

## 5. 하지 않는 것 (제안)

| 하지 않음 | 이유 |
| --- | --- |
| 길드 능력치 보너스, 길드 레벨 | 길드 유무로 강함이 갈리면 길드가 의무가 된다 |
| 기부·출석 할당 | 피로도와 눈치 보기 |
| 길드끼리 순위·전쟁 | 경쟁이 의무가 되면 피로도가 오른다 |

## 6. 화면

- 길드 섬: `GuildB` / PC `GuildPCB` (교류 탭 → 길드)
- 길드 만들기·관리(가입 신청, 길드원, 큰 토벌 출발 시각): `GuildManageB`

## 7. 남은 쟁점

1. 만들기 비용 10,000골드는 기본안(사용자 위임). 전체 수치 조정 때 다시 본다
2. 길드 섬 손님: 기본안(사용자 위임)으로 **허용하지 않는다.** 길드원끼리의 공간으로 둔다. 길드원은 자기 섬으로 손님을 부르면 된다
