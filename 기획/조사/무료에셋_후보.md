## 3. 주의 사항

1. **라이선스 섞기**
   - CC0, CC BY, OGA-BY는 한 게임에 함께 써도 충돌하지 않습니다. 각자의 표기 의무만 지키면 됩니다.
   - **CC BY-SA나 GPL로만 받은 그림을 고치면**(색 바꾸기, 잘라 붙이기 포함) 그 수정본을 같은 라이선스로 공개해야 합니다. 등급별 색 바꾸기를 할 예정이라면 SA 전용 에셋(Roguelike/RPG Items, Stendhal Jellyfish, Cartoony Cloud Images, Tiling Background Pack 등)은 피하는 편이 안전합니다.
   - 다중 라이선스 에셋은 CC BY나 OGA-BY 쪽을 고르면 SA 의무를 피할 수 있습니다.
2. **LPC 캐릭터**는 파일마다 라이선스와 작가가 다릅니다.
   - CREDITS.csv 기준으로 다수가 OGA-BY, GPL, CC BY-SA 다중 라이선스이고, 순수 CC0는 1,011건뿐입니다.
   - 쓰는 부품마다 크레딧을 모아 게임 안 크레딧 화면이나 링크로 제공해야 합니다. README의 문구는 "reasonably discovered by users"입니다.
   - CC BY-SA 전용 부품이 섞이면 수정한 스프라이트시트도 BY-SA로 공개해야 합니다.
3. **표기 방법**(CC BY, OGA-BY 공통): 작품 제목, 작가, 라이선스 이름과 링크, 원본 링크, 수정 여부를 적습니다. OGA FAQ 기준입니다. 예:
   - `검·활 아이콘: "broadsword", "pocket-bow" by Lorc, https://game-icons.net, CC BY 3.0 (색상 변경)`
   - `몬스터: "More RPG enemies!" by Stephen Challener (Redshrike), https://opengameart.org/content/more-rpg-enemies, CC BY 3.0`
   - 게임 안 "크레딧" 화면과 저장소의 `CREDITS` 파일 두 곳에 두는 것을 권합니다.
4. **작가가 따로 요구하는 표기**가 있습니다.
   - Antifarea(Twelve 16x18 sprites): OpenGameArt.org 링크가 필수입니다.
   - Redshrike(More RPG enemies): 이름과 OGA 링크를 요청합니다.
   - game-icons.net: 작가별로 표기합니다.
5. **DRM 조항**: CC BY 3.0과 CC BY-SA 3.0은 기술적 보호조치를 금지합니다. 웹 배포는 보통 괜찮지만, 앱스토어처럼 DRM이 걸리는 곳에 출시할 계획이 생기면 OGA-BY나 CC0 에셋으로 바꾸거나 따로 검토해야 합니다.
6. **DCSS 타일**은 저장소 루트에 LICENSE 파일이 없습니다(404). CC0 근거는 README 문구와 ARTISTS.md입니다. TILES_UNDER_UNKNOWN_LICENSE.md 목록의 파일은 쓰지 마세요.
7. 제3자가 올린 에셋(496 아이콘, Lorc 700 아이콘, Watercolour 샘플 등)은 올린 사람과 작가가 다릅니다. 표기할 때는 **원작자 이름**을 적으세요.
8. 다운로드할 때는 페이지의 라이선스 문구를 스크린샷이나 텍스트로 함께 보관해 두기를 권합니다. 작가가 나중에 라이선스를 바꿀 수 있기 때문입니다. OGA FAQ도 작가가 라이선스를 바꿀 수 있다고 명시합니다.

  - 작가 하위 도메인(kenney.itch.io, pixelfrog-assets.itch.io 등)은 프록시가 연결을 거부했습니다(403).
  - itch.io 본 도메인 목록 페이지는 Cloudflare 확인 화면("Just a moment...")만 돌아왔습니다. 우회는 하지 않았습니다.
  - 따라서 itch.io에만 있는 유명 무료 팩은 라이선스를 확인하지 못했습니다(예: Shikashi's Fantasy Icons, Pixel Frog의 Tiny Swords와 Pixel Adventure, Kenney itch 전용 신작, Ravenmore itch 추가분, Watercolour Monster 전체 18종).
  - Kenney는 Kenney 본인이 OGA에 올린 페이지(CC0)로 대신 확인했습니다. 다만 kenney.nl이나 itch 최신판과 내용 차이가 있을 수 있습니다.
- **kenney.nl**: 403이라 확인하지 않았습니다.
- **DCSS 타일 미리보기**: 이번 조사에서 직접 보지 않았습니다.
- **미리보기를 보지 못한 후보**: CraftPix 기사·마법사(전신 후보로 중요), Scrittl 32px 아이콘, Twelve 16x18 sprites, Kenney Pixel UI pack, Kenney Game icons(UI), RPG GUI construction kit, Fantasy UI Elements by Ravenmore, Stendhal Jellyfish, Crab, Floating island(Santoniche).
- **Tiny Creatures에 해파리, 게, 큰 새가 있는지**: 전체 팩을 받지 않아 확인하지 못했습니다(미리보기에서 용과 날개 달린 생물은 보임).
- **CraftPix "2D Game Archer Character Sprite"**: 본문에 링크가 있으나 페이지를 열지 않았습니다.
- **GitHub API**: 이 세션에서는 GitHub API 저장소 접근이 막혀 있습니다. 그래서 raw.githubusercontent.com의 개별 파일(license.txt, README.md, CREDITS.csv, TILES_UNDER_UNKNOWN_LICENSE.md)만 읽었고, 저장소 전체 파일 목록은 보지 못했습니다.
