## 1. 파티 흐름 (제안)

```text
모집 만들기 또는 모집 목록에서 지원 → 준비완료 → (모두 준비되면) 자동 출발 → 결과·재생
```

### 모집 만들기

- 관문 화면에서 "파티 모집"을 누른다. 정할 것은 **모집 인원(2~4명)** 하나뿐이다.
- 모집 글에는 관문 이름, 현재 인원, 파티 전투력 합계, 지금 구성의 예상 결과가 자동으로 표시된다.
- 최소 전투력 같은 조건은 두지 않는다. 보스가 인원과 관계없이 고정이라서, 약한 사람이 들어와도 손해가 없다.

### 지원

- 모집 목록에서 "지원"을 누르면 승인 없이 바로 합류한다. 방장의 수락을 기다리지 않는다.
- 방장은 필요하면 파티원을 내보낼 수 있다. 기본 진행에는 필요 없는 기능이다.
- 목록은 예상 결과가 '승리'에 가까운 모집 글을 위에 보여준다. "당신이 들어가면 이길 수 있어요" 표시를 붙인다.

### 준비완료와 출발

- 파티원은 각자 "준비완료"를 누른다. 자동준비를 켜 둔 사람은 합류하는 순간 준비완료가 된다(3장).
- **모집 인원이 다 차고 모두 준비완료가 되면 5초 뒤 자동으로 출발한다.** 방장이 출발을 누를 필요가 없다.
- 인원이 덜 차도 방장은 "지금 출발"을 누를 수 있다. 준비완료한 사람만 함께 간다.
- 출발하면 각자의 능력치를 그 순간 기준으로 고정해 전투를 계산한다. 결과는 파티원 모두에게 같은 재생으로 보인다.

## 2. 자동매칭 (제안)

"자동매칭"을 누르면 같은 관문을 노리는 사람들과 알아서 묶인다.

| 규칙 | 내용 |
| --- | --- |
| 먼저 넣을 곳 | 자리가 남은 모집 글이 있으면 그 파티에 먼저 넣는다 |
| 출발 시점 | 모인 사람들의 합계로 **예상 결과가 승리가 되는 순간** 바로 출발한다. 4명을 채울 때까지 기다리지 않는다 |
| 혼자로 충분할 때 | 혼자서도 예상 승리면 매칭을 기다리지 않고 혼자 출발한다 |
| 우선순위 | 아직 이 관문을 깨지 못한 사람끼리 먼저 묶는다. 부족하면 대기 중인 도우미(이미 깬 사람)로 채운다 |
| 기다리는 동안 | 자동 탐사는 그대로 계속된다. 접속을 끊어도 대기는 유지된다. 그동안 전투력이 오르면 예상 결과도 다시 계산한다 |
| 대기 해제 | 관문을 토벌하면 자동으로 빠진다. 언제든 직접 끌 수 있다 |

- 매칭은 이길 수 있는 구성일 때만 출발하므로, 자동매칭에서는 지는 전투가 나오지 않는다.
- 기본값은 **꺼짐**이다. 관문에 처음 도착했을 때의 안내에서 "자동매칭을 켤까요?"를 한 번만 묻는다. 첫 관문은 직접 도전해 보고 싶은 사람도 있기 때문이다.

## 3. 자동준비 (제안)

- 켜 두면 파티에 합류하는 즉시 준비완료가 된다. 패배 뒤 같은 파티로 다시 도전할 때도 자동으로 준비된다.
- 기본값은 **켜짐**이다. 준비완료를 누르지 않아서 파티 전체가 기다리는 일을 막는다.
- **자동매칭 + 자동준비**를 함께 켜 두면 접속하지 않아도 관문이 토벌된다. 결과는 다음 접속 성장 보고 첫 줄에 나오고, 전투 장면은 다시 재생할 수 있다.

> 돌개바람 수리를 토벌하고 폭풍의 벽을 뚫었어요. 함께 간 모험가 2명 · 38초 · 다시 보기

## 4. 참가 조건

| 대상 | 참가 | 받는 것 |
| --- | --- | --- |
| 그 관문 단계에 도착했지만 아직 못 깬 사람 | 가능 | 승리하면 첫 토벌 보상과 다음 구간 개방 |
| 이미 그 관문을 깬 사람 (도우미) | 가능 | 도움 기록 (5장) |
| 그 관문 단계에 아직 도착하지 못한 사람 | 불가 | — |

- 앞 관문을 건너뛰는 일은 생기지 않는다. 관문 단계에 도착해야 참가할 수 있고, 관문 단계에는 앞 관문을 깨야 도착한다.
- 도우미의 전투력에는 상한을 두지 않는다. 강한 친구가 약한 친구를 끌어주는 플레이를 허용한다.

## 5. 보상 (제안)

- 보상은 각자 받는다. 인원수로 나누지 않고, 주사위나 분배 경쟁도 없다.
- 첫 토벌 보상(희귀 무기·골드·거점 장식·구간 개방)은 [첫관문_상세 5장](./첫관문_상세.md#5-보상-제안)과 같다.
- 도우미에게는 반복해서 쌓이는 재화를 주지 않는다. 1분짜리 도움을 반복해 탐사보다 많이 버는 일을 막고, 도와주기가 의무가 되지 않게 하려는 것이다.
- 대신 도움 횟수를 기록하고, 한 번씩만 받는 목표를 둔다.

| 도움 목표 | 보상 (예시) |
| --- | --- |
| 처음으로 다른 모험가의 첫 토벌을 도움 | 거점 장식 하나 |
| 10명의 첫 토벌을 도움 | 칭호 |
| 자기보다 전투력이 절반 이하인 모험가를 도와 승리 | 거점 장식 하나 |

## 6. 전투 규칙과 검산

### 규칙

- 1~4인이 매초 각자 공격한다. 적이 살아 있으면 반격한다. 기존 초안 그대로다.
- **변경 제안: 보스 피해를 살아 있는 파티원의 최대 생명력에 비례해 나눈다.** 기존 초안은 똑같이 나누는 방식이었다.

### 변경을 제안하는 이유

똑같이 나누면 약한 사람이 먼저 쓰러지고, 그만큼 공격력이 빠진다. 그래서 합계 전투력이 기준보다 높은데도 지는 경우가 생긴다. 생명력에 비례해 나누면 모두가 같은 비율로 버티므로, **파티 전투력 합계만 보면 결과가 정확히 맞는다.** 연출에서는 "앞에 선 강한 사람이 더 많이 맞아 준다"로 보여준다. 1인 전투와 같은 전투력끼리 모인 파티의 결과는 두 방식이 똑같다.

| 관문 | 구성 | 합계 | 똑같이 나눌 때 | 생명력 비례로 나눌 때 |
| --- | --- | ---: | --- | --- |
| 첫 관문 | 600 + 340 | 940 | 패배 (보스 10% 남음) | 승리 |
| 두 번째 관문 | 1,600 + 800 | 2,400 | 패배 (보스 6% 남음) | 승리 |
| 두 번째 관문 | 1,800 + 600 | 2,400 | 패배 (보스 10% 남음) | 승리 |
| 두 번째 관문 | 1,800 + 560 | 2,360 | 패배 (보스 12% 남음) | 승리 |

### 1~4인 결과 (생명력 비례 분배)

| 관문 | 구성 | 합계 | 결과 | 전투 시간 (방 포함) | 남은 생명력 |
| --- | --- | ---: | --- | ---: | ---: |
| 첫 관문 (솔로 기준 938) | 혼자 925 | 925 | 패배 (보스 4%) | 47초 | — |
| | 혼자 938 | 938 | 승리 | 48초 | 1% |
| | 2인 470 + 470 | 940 | 승리 | 48초 | 1% |
| | 4인 각 235 | 940 | 승리 | 48초 | 1% |
| | 도움 900 + 100 | 1,000 | 승리 | 48초 | 13% |
| | 도움 1,300 + 600 | 1,900 | 승리 | 25초 | 76% |
| | 4인 각 925 | 3,700 | 승리 | 14초 | 94% |
| 두 번째 관문 (솔로 기준 2,345) | 혼자 2,272 (40단계 도착) | 2,272 | 패배 (보스 6%) | 47초 | — |
| | 2인 각 2,272 | 4,544 | 승리 | 26초 | 74% |
| | 도움 2,500 + 800 | 3,300 | 승리 | 35초 | 50% |
| | 3인 각 800 | 2,400 | 승리 | 48초 | 3% |
| | 4인 각 2,272 | 9,088 | 승리 | 14초 | 93% |

- 위 표는 직업 구분 없이 계산했다. 같은 직업끼리면 결과는 인원수와 관계없이 합계로만 정해진다. 4인이면 전투가 짧아지고 여유 있게 이긴다.
- 직업(전사·사냥꾼·마법사)이 섞여도 결과는 합계 그대로다. 조합 보너스는 없다([직업_상세.md](./직업_상세.md)).
- 관문에 막 도착한 사람(첫 관문 925, 두 번째 관문 2,272) 둘이 모이면 바로 이긴다. 자동매칭은 대부분 2인에서 출발한다.

## 7. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 출발 전 탈퇴 | 언제든 자유. 불이익 없음 |
| 방장이 나감 | 가장 먼저 들어온 파티원이 방장이 된다. 모두 나가면 모집 글이 사라진다 |
| 준비완료 후 접속 종료 | 상관없다. 준비완료 상태가 유지되고 그대로 출발한다 |
| 준비하지 않은 채 오래 머묾 | 10분이 지나면 자동으로 파티에서 빠지고, 모집 글에 자리가 다시 난다 |
| 전투 중 접속 종료 | 상관없다. 전투는 출발 순간에 이미 계산되어 있다 |
| 패배 | 모집 파티는 30초 동안 유지되고 "다시 도전"을 고를 수 있다. 같은 구성이면 같은 결과이므로 예상 결과를 함께 보여준다. 자동매칭 파티는 질 구성으로 출발하지 않는다 |
| 도전 중 다른 탐사 | 자동 탐사는 파티와 관계없이 계속된다 |

- **설정:** 자동매칭(기본 꺼짐)과 자동준비(기본 켜짐)를 켜고 끄는 항목 두 개.

## 8-1. 큰 토벌 (사용자 확정 2026-11-01, 세부는 제안)

사용자 결정: 큰 토벌은 매칭하지 않는다. **하루 한 번, 길드나 섬 동행끼리 기록을 경신하는** 콘텐츠다. 관문은 1~4인 매칭 그대로다.

| 항목 | 내용 (제안) |
| --- | --- |
| 함께 가는 무리 | 같은 **길드** 또는 같은 **섬 동행**([RP_교류.md](./RP_교류.md) 1-6). 무리마다 기록이 따로 남는다. 혼자도 갈 수 있다 |
| 인원 | 1~8명. 적으면 기록이 낮을 뿐 지지 않는다 |
| 하는 방법 | 그날 "참가"를 걸어 두면 끝이다. 정해진 시각(기본 22:00, 무리가 바꿀 수 있음)에 걸어 둔 사람끼리 자동으로 출발한다. 접속하지 않아도 되고 준비완료도 없다 |
| 우두머리 | 쓰러지지 않는다. **60초 동안 준 피해의 합**이 기록이다. 구역이 열릴 때마다 우두머리가 바뀐다 |
| 운 | 없다. 같은 사람·같은 프리셋이면 기록도 같다. 그래서 기록이 오르면 무리가 강해졌다는 뜻이고, 이것이 매일 보는 성장 표시가 된다 |
| 표시 | 무리 최고 기록, 오늘 예상 기록과 차이(%), 각자의 몫 |
| 보상 | **기록만큼 준다**(사용자 확정 2026-11-01). 경신 보상·기록 단계 보상은 두지 않는다. 오늘 기록에 비례해 구름 수정과 골드를 받고, 같은 무리는 **모두 같은 양**을 받는다(제안: 각자 준 피해로 나누면 치유·막기 역할이 손해를 보므로). 폭풍의 핵과 관문 진행은 주지 않는다 |
| 순위 | 다른 무리와의 순위는 두지 않는다(제안). 경쟁이 의무가 되면 피로도가 오른다. 자기 무리의 기록만 본다 |
| 프리셋 | 파티 프리셋으로 나간다 |

- 화면 시안: `RaidB` (원정 탭 → 던전 → 큰 토벌).
- 남은 쟁점:
  1. **길드는 아직 설계하지 않았다.** 인원, 만들기·가입 방법, 섬 동행과의 관계를 정해야 한다.
  2. 한 사람이 길드와 동행 양쪽에 있으면 하루 한 번을 어느 쪽에 쓸지(제안: 하루 한 무리만 고름)
  3. 기록 대비 보상 비율(시안: 기록 2만당 구름 수정 1개)은 전체 수치 조정 때 정한다. 인원이 많을수록 기록이 커지므로 혼자·소수로 가는 사람이 손해 보지 않게 할지도 본다.

## 9. 서버가 필요한 부분

- 모집 목록, 지원, 준비 상태, 자동매칭 대기열, 출발 순간의 능력치 고정과 전투 계산은 여러 사람의 데이터를 함께 다루므로 서버가 필요하다.
- 혼자 만드는 첫 시제품에서는 컴퓨터가 움직이는 가짜 모험가로 모집 목록과 매칭을 흉내 낸다. 화면에는 가짜 기능이라는 것을 내부 개발 표시로만 구분한다.

## 10. 낮은 피로도 점검

| 기준 | 이 설계 |
| --- | --- |
| 꼭 필요한 조작 | 지원 또는 자동매칭 버튼 하나. 자동준비가 기본이라 준비완료도 누르지 않아도 된다 |
| 기다림 | 대기 중에도 탐사가 계속되고, 접속을 끊어도 된다 |
| 역할 조율 | 전사·사냥꾼·마법사로 역할이 나뉘지만 조합 제약은 없다. 자동매칭과 모집은 직업을 보지 않는다 |
| 실패 | 자동매칭은 질 구성으로 출발하지 않는다. 모집 파티도 잃는 것이 없다 |
| 반복 의무 | 도우미 보상은 일회성 목표뿐이다 |

## 11. 남은 쟁점

1. **매칭 인원:** 이용자가 적으면 자동매칭이 오래 걸린다. 이때는 혼자 이길 수 있을 때까지 기다리게 된다(첫 관문 약 20분, 두 번째 관문 약 7시간). 일정 시간이 지나면 가짜 모험가(NPC 동료)로 채울지 정해야 한다.
2. **오프라인 자동 토벌과 첫 토벌의 감동:** 자동매칭으로 접속하지 않은 동안 깨면, 첫 토벌 장면을 직접 보지 못한다. 성장 보고에서 "다시 보기"를 가장 크게 보여주는 것으로 보완한다.
3. **도우미 동기:** 재화 보상이 없어서 돕는 사람이 적을 수 있다. 친구 관계가 생기면 친구를 도울 때만 작은 보상을 줄지 다시 본다.
4. **생명력 비례 분배의 연출:** 강한 사람이 더 맞는 모습을 어떻게 자연스럽게 보여줄지는 화면·연출 작업에서 정한다.
