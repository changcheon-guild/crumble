# 경제와 거래 상세 기획

- 작성일: 2026-11-01
- 연결 문서: [게임기획서.md](./게임기획서.md), [장비_상세.md](./장비_상세.md)
- 상태: 제안안이다. 수치는 모두 임시값이다. 시스템을 모두 정한 뒤 성장 속도와 함께 한꺼번에 조정한다.

## 0. 기준

| 구분 | 내용 |
| --- | --- |
| 기존 기본안 | 남는 장비와 재료를 팔고, 원하는 장비나 강화 재료를 산다. 거래는 성장 경로를 넓혀 주지만, 기본 진행에 시장 감시를 요구하지 않는다 |
| 기존 제안 | NPC 상점은 기본 물품과 최소한의 판매처를 맡는다. 유저 거래소는 장비·재료·외형 같은 선택적인 거래를 맡는다 |
| 이번 문서 | 재화 흐름, NPC 상점, 유저 거래소, 거래 가능 품목, 수수료, 자동 판매 |

## 1. 재화 흐름 (제안)

```text
들어오는 곳: 탐사 골드 · 관문 첫 토벌 골드 · NPC에 판매 · 거래소 판매
나가는 곳:   칸 강화 · 재련 · 영웅·전설 제작 · 거래소 구매 · 거래소 수수료 · 거점 꾸미기
```

- 골드가 가장 많이 쓰이는 곳은 **칸 강화**다. 자동 강화를 켜 두면 탐사 골드가 자연스럽게 성장으로 바뀐다. 골드가 쌓이기만 하고 쓸 곳이 없는 상태를 막는다.
- 거점 꾸미기(장식 사기)는 전투력과 관계없는 골드 사용처다. 강화를 다 한 뒤에도 골드에 의미가 남는다.

## 2. NPC 상점 (제안)

| 기능 | 내용 |
| --- | --- |
| 팔기 | 어떤 장비든 정해진 값에 판다. 값은 등급과 장비 레벨로 정한다 |
| 사기 | 하늘돌을 정해진 값에 산다. 하늘돌이 모자라 강화가 막히는 일을 막는다 |
| 사지 않는 것 | 장비, 구름 수정, 폭풍의 핵는 NPC가 팔지 않는다. 운이나 거래, 제작으로만 얻는다 |
| 거점 장식 | 골드로 사는 꾸미기 물품 |

## 3. 유저 거래소 (제안)

### 방식

- **판매자가 가격을 붙여 올리고, 구매자는 그 가격에 바로 산다.** 경매나 입찰은 없다. 기다리거나 경쟁하는 부담을 줄인다.
- 팔리면 판매 금액에서 **수수료 5%**를 떼고 받는다. 판매자가 접속하지 않아도 거래된다.
- 올린 물건은 7일이 지나면 판매자의 보관함으로 돌아온다. 보관함이 가득해도 돌아온 물건은 잃지 않는다.

### 거래 가능 품목

| 품목 | 거래 | 이유 |
| --- | --- | --- |
| 희귀 이상 장비 | 가능 | 주요 거래 품목. 특히 다른 직업 계통 장비 |
| 일반·고급 장비 | 불가 | 양이 너무 많고 가치가 낮다. 자동 재료화로 처리한다 |
| 하늘돌 | 불가 | NPC가 정가에 판다 |
| 구름 수정 | 가능 | 영웅 제작과 재련을 서두르고 싶은 사람에게 |
| 폭풍의 핵 | 불가 | 관문을 직접 깬 기록이다 |
| 관문 첫 토벌 보상 장비 | 불가 | 토벌 기념품. 귀속으로 둔다 |
| 거점 장식 | 가능 | 외형 거래 |

### 추천과 검색

- 거래소 첫 화면에는 **추천**만 보인다. 내 직업 계통이고 장착하면 전투력이 오르는 장비를 "장착하면 전투력 +120"과 함께 보여준다.
- 자세히 찾고 싶은 사람에게는 검색을 준다. 부위, 계통, 등급, 장비 레벨, 옵션(예: "연사 +1"), 가격으로 거른다.
- 물건마다 **최근 거래 가격**을 함께 보여준다. 시세를 따로 조사하지 않아도 된다.

## 4. 자동 판매 (제안)

거래가 하고 싶은 사람만 하는 활동이 되도록, 파는 쪽도 자동으로 둘 수 있다.

- 자동 관리 항목 **"다른 계통 희귀 이상 장비를 거래소에 올리기"**를 둔다. 켜 두면 보관함의 다른 계통 장비를 최근 거래 가격으로 자동 등록한다. 최근 거래가 없으면 NPC 판매가의 3배로 등록한다.
- 7일 동안 팔리지 않으면 NPC에 자동으로 판다. 이 동작도 켜고 끌 수 있다.
- 기본값은 꺼짐이다. 처음 다른 계통 희귀 장비를 얻었을 때 한 번만 "거래소에 자동으로 올릴까요?"라고 묻는다.
- 팔린 결과는 성장 보고에 한 줄로 알린다. 예: "보관해 둔 마법 계통 지팡이가 4,200골드에 팔렸어요".

## 5. 경제가 무너지지 않게 (제안)

| 위험 | 대책 |
| --- | --- |
| 골드가 끝없이 쌓임 | 강화 비용이 단계마다 커지고, 거래소 수수료와 거점 꾸미기가 골드를 흡수한다 |
| 부계정으로 장비 몰아주기 | 관문 보상과 증표는 거래 불가. 다른 품목도 이상 거래(시세와 크게 다른 가격의 반복)를 기록해 운영자가 본다 |
| 거래소를 계속 봐야 손해를 안 봄 | 바로 구매 방식이고, 최근 거래 가격을 보여주며, 자동 판매가 있다 |
| 장비 가격 폭락 | 일반·고급은 거래 불가로 시장에 쌓이지 않는다. 팔리지 않으면 NPC가 받아 준다 |

## 6. 서버가 필요한 부분

- 유저 거래소, 최근 거래 가격, 자동 판매, 이상 거래 기록은 여러 사람의 데이터를 다루므로 서버가 필요하다.
- 혼자 만드는 첫 시제품에서는 가짜 모험가들이 사고파는 모의 거래소로 흉내 낸다.

## 7. 이어서 정할 것

1. **전체 수치 조정:** 탐사 골드, NPC 판매가, 하늘돌 가격, 강화 비용, 제작 비용을 성장 속도와 함께 맞춘다. 목표는 '자동 강화만으로 강화 단계가 탐사 구간에 맞춰 오르는' 정도다.
2. **유료 요소:** 정하지 않았다. 생기면 재련과 거래 규칙을 다시 본다.
